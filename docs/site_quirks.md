# Site quirks (application portals)

Read ONLY the entry for the site you are about to submit on (search this file for the site or ATS name). Add new findings here, one bullet per site, dated. Do not copy these into CLAUDE.md.

- Flatchr (HGH): no account; fields re-render under Chrome auto-translate → refill + re-check right before submit; letter pasted as text.
- Stellantis (jobs.groupe-psa.com): account; ONE CV slot only (RangeExtender CV, not replaceable); max 3 cover letters (full). "Send" needs two clicks.
- Schneider (frcareers-se.icims.com): form inside an iframe; NEVER load the iframe src / URLs with login codes (logs out). Upload by adoptNode-ing the iframe file input into the top doc, file_upload, move back + 'change' event. Job step selects: Un stage / 6 mois / Courant (C1). Profile dropdowns need real clicks.
- SAP SuccessFactors (Alstom, EssilorLuxottica LUXGRP, Colas speig): account per company; sessions expire fast.
- Workday (Renault alliancewd, Daher, Thales): sign-in required; Renault form asks street address (on file in 10-screening-answers.md: autofill, never ask). Renault apply URL + `/apply/useMyLastApplication` prefills everything; Questions step = school textarea (real typing), diploma + duration selects, start date (real typing DDMMYYYY). Alpine Racing postings live on the same tenant at `/alpine-racing-careers` (same login) and additionally require sex, birth date/country/state/city, marital status, nationality (2026-11-14). ALPINE CARS postings sit on renault-group-careers but ask other questions: course start date, 'When do you graduate?' and a diploma-title textarea (no selects). Chrome auto-translate can switch the form to English mid-run: check steps by 'N of 5' and confirm by the URL jobTasks/completed/application, not French text. Option order in the Renault selects: diploma index 5, duration index 1 (index 0 = placeholder). The consent checkbox sits near the page bottom, so recompute its position after scrolling.
- SII (sii-group.com), Dover (HyLight), SmartRecruiters (Netatmo), Tally (Revolty): no account, CV only → paste letter in message box.
- SmartRecruiters oneclick form (Somfy, 2026-11-09): CV goes in the lower "resume" dropzone, because the top "Apply easily" autofill turns projects into broken experience cards. File inputs sit in shadow DOM: move the input to body, file_upload, move back. Do not dispatch an extra 'change' on "Other attachments" (it attaches twice). Fill city and phone by real typing.
- HelloWork follow-up (2026-11-09): after the first submit, many offers show a second step asking for a phone (`sav2_field1`) that must be submitted too; leaving early silently loses the application.
